# Fig 25.16: end mirror relocated for testing prisms in the Twyman-Green interferometer

Construction schematic: right-angle prism turning the beam 90 degrees by total reflection on its hypotenuse; M1 at B returns it.
B' marks the in-line position; the dashed quarter circle is the relocation. Labels from the figure: collimator, beamsplitter, O, M2, A, prism, M1, B, B', telescope. No numbers printed.
